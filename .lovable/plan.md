# Mobile navigation and admin portfolio history

## What will change
- Add an always-visible menu button in the top-right of signed-in mobile pages. It opens every page link, account settings, the control room for staff, and sign out.
- Keep the existing bottom shortcuts, while making the full navigation available without rotating the phone.
- Expand the control room so admins can open each member's complete portfolio and transaction history.
- Let admins correct investment start and unlock dates with validation and an audit-labelled action.
- Add an admin-only historical award form: choose a member, amount, asset, plan, and a date from 1999 onward. It creates a completed, clearly labelled admin-awarded investment with matching lock, payout, and ROI history; it does not silently alter the member's current wallet balance.
- Change the “Welcome to Terravest” announcement date to 2007.

## Safety and behavior
- All history creation and date changes are checked in the backend and restricted to admins.
- Awarded records will be visibly identified as admin-awarded rather than presented as organic deposits.
- Dates cannot be before 1999 or in the future, and unlock dates must follow start dates.

## Validation
- Check the mobile menu at the current phone size.
- Test admin member selection, history viewing, date editing, and historical award creation.
- Confirm ordinary members can only see their own portfolio and cannot call the admin actions.
